# 포디엄 버그 기록

고친 버그는 **빠짐없이 여기 적는다** (2026-08-25 사용자 지시). CLAUDE.md 의 '함정' 절은
*앞으로 이렇게 하라*는 규칙을 담고, 이 파일은 *무엇이 어떻게 깨졌었나*는 이력을 담는다.
같은 증상이 몇 달 뒤 다시 올라올 때 "그때 뭐였더라"를 되풀이하지 않기 위한 것이다.

## 적는 방법

새 항목은 **맨 위에** 쌓는다. 한 건에 다섯 줄:

```
### YYYY-MM-DD  한 줄 제목
- **증상** 사용자·화면에서 무엇이 잘못 보였나 (실제 값을 그대로 인용)
- **원인** 왜 그랬나. 코드 한 줄이면 그 줄을, 구조 문제면 구조를
- **수정** 무엇을 어떻게 바꿨나 (함수·파일 이름)
- **재발 방지** 같은 실수가 다시 나면 어디서 잡히나. 없으면 '없음'이라고 적을 것
- **커밋** 해시
```

**발견 경위도 한 줄 적는다** — 사용자 제보인지, 로그인지, 대조 중 우연인지. 어느 경로가
실제로 버그를 잡아내는지가 쌓이면 그게 곧 검수 전략이다. 지금까지는 **사용자가 카드
스크린샷을 던진 것**이 압도적으로 많다.
